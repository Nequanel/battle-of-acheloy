# Ахелой 917

Кинематографична битка от първо лице в браузъра. Ти си българският пълководец при Ахелой, 20 август 917 г.
Крещиш на войската с клавишите 1–6 и я водиш през битката.

```
npm install
npm run dev
```

Отвори http://localhost:5173. На слаб компютър: http://localhost:5173/?low

Дизайн и план: [docs/design.md](docs/design.md)
